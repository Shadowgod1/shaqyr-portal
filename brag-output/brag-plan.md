# brag-plan — iler.kz

**What:** ILER — системный интегратор ИТ и ИБ из Казахстана (с 2015 г.).
**For whom:** крупные компании госсектора и финансов, которым нужна защита и инфраструктура «под ключ».
**Sets it apart:** 40+ официальных партнёров-вендоров, 100+ проектов, полный цикл от presale до поддержки.
**Most impressive claim:** «официальные партнёры более 40-ка мировых производителей ИТ и ИБ решений».
**Visual hook:** стена логотипов вендоров, собирающаяся под счётчик 0 → 40+.
**Real UI to show:** круги услуг (PRESALE → АУДИТ → ПРОВЕРКА КОНЦЕПЦИИ → ВНЕДРЕНИЕ → ПОДДЕРЖКА), 3D-ключ/шестерня/замок, сертификаты, зелёная карточка «Партнер, которому можно доверять».
**Tone:** default → polished-ish: чёрный фон, неоново-зелёный #25DA81, Benzin для заголовков, Gilroy для текста.
**Share caption:** 40+ мировых вендоров ИТ и ИБ, 100+ проектов в госсекторе и финансах — ILER, системный интегратор Казахстана с 2015 года.
