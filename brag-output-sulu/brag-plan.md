# brag-plan — SuluSystems

**Source:** Shadowgod1/sulusystems-vault (база знаний проекта) + живой сайт https://sulusystems.kz
(IT-Fusion-kz/sulusystems недоступен в этой сессии; кода UI в vault нет, поэтому визуал и копирайт — с сайта).

**What:** медицинская ERP-система для клиник эстетической медицины и сетей.
**For whom:** владельцы и руководители косметологий, центров превентивной медицины, сетей клиник.
**Sets it apart:** не CRM-календарик, а «неделимая цепочка одного визита»: пациент → специалист → кабинет → списание → DocFactory → финансы; ИИ-ассистент руководителя.
**Most impressive claim:** WhatsApp-напоминания снижают долю неявок с 25% до 4%.
**Visual hook:** вопрос руководителя печатается в чат ИИ-ассистента и получает ответ с цифрами.
**Tone:** default → спокойный, премиальный: кремовый #F6F3ED, тёмно-зелёный #173F33, Playfair Display + Inter.
**Share caption:** см. share-copy.txt
