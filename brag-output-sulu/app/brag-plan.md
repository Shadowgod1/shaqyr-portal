# brag-plan — SuluSystems: приложение пациента (v2, по исходному коду)

**Source:** архив `sulusystems-production` (исходный код). Пациентское приложение `mobile-app/`
(Expo SDK 54 + react-native-web) собрано под веб (`expo export --platform web`) и запущено в
headless Chromium; все запросы к `https://sulusystems.kz/api/**` подменены демо-данными
(пациент «Айгерим», клиника «Sulu Aesthetic», услуги и цены — вымышленные, но в формате
реального API из `src/types.ts`). Часы зафиксированы: вт 13.10.2026, 10:25, Алматы.

Правки только в демо-сборке (в исходники не вносились):
- `src/lib/storage.ts`: на вебе токены в AsyncStorage (SecureStore на вебе пуст);
- `branding/brand.config.json`: `features.recovery = false` (трекер — для другой клиники сети).

Каждый экран — настоящий скриншот приложения, каждое касание — реальный клик Playwright,
координаты пальца в ролике = координаты клика.

**Hook:** «Ваша клиника в кармане» (welcomeText из brand.config) + главная пациента.
**Key action:** запись: Записаться → Биоревитализация → Динара Сапарова → чт 15 → 13:00 → согласие → «Заявка отправлена».
**Result:** визит на главной → клиника подтверждает в чате → абонемент и бонусы в «Балансе».
**Punchline:** «А у клиники — вся цепочка визита» (6 звеньев ERP с сайта) → «Попробуйте SuluSystems бесплатно», sulusystems.kz.

Форматы: 1920×1080 и 1080×1920, 30 fps, 25 s. Звук: D-мажор, 100 BPM, клики касаний с тихими нотами пентатоники, колокольчик на «Заявка отправлена», арпеджио на звеньях ERP.
