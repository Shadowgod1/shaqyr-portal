# SuluSystems — редизайн лендинга

Статический макет редизайна https://sulusystems.kz/, сделанный по скиллу
[`frontend-design`](../../.claude/skills/frontend-design/SKILL.md). Один файл `index.html`, без сборки и зависимостей —
открывается прямо в браузере.

## Направление

**Якорь: Swiss.** Текущий сайт говорит голосом бьюти-индустрии — кремовая бумага, Playfair, лесной зелёный.
Так выглядит любая косметология, а не софт, который продаёт точность. Swiss-типографика говорит главное
обещание продукта — списание до 0,1 мл, SlotGuard, ИДС по стандартам Минздрава — языком медицинской
документации: белое поле, одна гарнитура, сетка, которую видно.

- **Поверхность:** `#FFFFFF` и `#F7F7F8` для чередующихся секций.
- **Шрифт:** Helvetica Neue (→ Helvetica → Arial), одно семейство для заголовков и текста, `tabular-nums`.
- **Акцент:** International Orange `#FF4F00` — только CTA, ключевые числа и шкалы.
- **Структура:** 12-колоночная сетка с видимыми направляющими в первом экране, волосяные линии 1px,
  выключка влево, номера разделов 01–08 как элементы композиции.

**Отличительный приём — шкала шприца.** Каждый раздел открывается градуированной линейкой
(мелкое деление 8px, крупное 80px). При прокрутке оранжевая заливка доходит до позиции раздела в странице
(01 = 1/8 … 08 = вся шкала) — страница «набирается» как шприц. В первом экране то же
число вынесено крупно: «0,1 — мл, шаг списания препаратов».

## Контент

Все тексты, цены и тарифные опции взяты с текущего сайта. Убрано: эмодзи-иконки, блок
«Демо-видео скоро» (его заменяет форма записи на демо), декоративный подзаголовок «ERP нового поколения».
Ссылки «Вход», «Попробовать бесплатно», документы и API ведут на реальные адреса sulusystems.kz.

## Что нужно доделать при переносе в продакшн

- **Форма демо.** В макете нет бэкенда: отправка открывает WhatsApp на номер +7 776 429 03 00 с
  заполненной заявкой. При переносе подключите её к вашему текущему обработчику заявок.
- SEO-мета (OG, гео, верификации) из текущего `index.html` перенести в шаблон.
