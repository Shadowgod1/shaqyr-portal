# SuluSystems — редизайн лендинга

Всё, что относится к редизайну https://sulusystems.kz/.

| Папка | Что внутри |
|---|---|
| `app/` | **Основной редизайн.** React + Vite + Tailwind v4 + shadcn/ui, 3D на Three.js, анимации GSAP ScrollTrigger и Motion. |
| `original/` | Полная копия текущего сайта: HTML 7 страниц, JS/CSS-бандлы, шрифты, картинки, все тексты (`content/`), скриншоты (`screens/`). |
| `assets/` | Оригинальные картинки, которые использует редизайн (фото первого экрана, фавикон, платёжные логотипы). |
| `index.html` | Первый статический вариант (Swiss, без 3D), оставлен для сравнения. |

## Запуск `app/`

```bash
cd redesign/sulusystems/app
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в app/dist (относительные пути — можно открыть с любого адреса)
```

## Что сохранено с оригинала

- **Тексты** — все строки, цены, тарифы, ответы FAQ, подписи формы и плейсхолдеры (`app/src/content.ts`, исходник — `original/content/home-all-text.txt`).
- **Картинки** — фото первого экрана, знак SuluSystems (favicon), логотипы Visa / Mastercard.
- **Цвета** — `#173F33` изумруд, `#F8F5EF` кремовый, `#B8966E` золото, `#EBF4F0` мята, `#111827` текст, `#064E3B` theme-color, `#C0392B` красный.
  Два цвета чуть затемнены ради контраста 4.5:1 на кремовом фоне (золото для мелких подписей `#7d6243`, серый `#5b6270`).
- **Шрифты** — Playfair Display, Inter, Golos Text.
- **Анимации** — параметры из бандла оригинала: появление `opacity 0, y 28 → 0` за 0.55 с, шаг 0.12 с; шапка — spring (damping 22, stiffness 320); раскрытие FAQ по высоте.
- **Поведение** — форма отправляет `POST /api/leads` с `{name, phone, clinic, plan, website}` (website — ловушка для ботов), показывает те же сообщения успеха/ошибки; карточки «Кому подходит» и Enterprise подставляют тариф в форму; «Создать аккаунт» и «Поговорить с продавцом» ведут к форме, как на сайте.

## Стили

Переключатель в шапке, все три — в палитре оригинала:

1. **Классика** — как сейчас: кремовый фон, изумруд, Playfair.
2. **Ночь** — тёмный изумруд (оттенки из палитры Astryx), кремовый текст, золотые акценты.
3. **Клиника** — белый клинический фон, изумруд и мята, заголовки Golos Text.

## 3D и анимации

| Раздел | Эффект |
|---|---|
| Первый экран | Three.js: «живая клетка» (шейдер с шумом и френелем), орбиты с молекулами, золотая пыль; параллакс от мыши; фото на 3D-карточке с наклоном и бликом |
| ERP, а не CRM | 6 шагов визита на 3D-цилиндре, поворот привязан к прокрутке (GSAP, pin + scrub + snap); на телефоне — сетка |
| ИИ-ассистент | Панель чата в перспективе выпрямляется при прокрутке; ответ «печатается» |
| Кому подходит, Возможности, Тарифы | Наклон карточек за курсором с бликом (техника Vanilla-Tilt) |
| Проблемы | Карточки переворачиваются: проблема → решение (наведение или нажатие) |
| Возможности | Карточки поднимаются из наклонённой плоскости (GSAP batch) |
| Демо | Экран «лежит» в 3D и встаёт при прокрутке |
| Финальный блок | Знак SuluSystems из favicon, выдавленный в 3D, золотой металл |

`prefers-reduced-motion` отключает всё движение; WebGL-сцены останавливаются вне экрана и освобождают память при размонтировании.

## Использованные скиллы и инструменты

Установлены в `.claude/skills/` корня репозитория:

- `frontend-design` (Ilm-Alan) — первый вариант (`index.html`).
- `ui-ux-pro-max` (nextlevelbuilder) — дизайн-система, правила доступности, пресеты GSAP, гайд по Three.js.
- `shadcn` (shadcn-ui/ui) — компоненты: Button, Card, Badge, Accordion, Field, Input, Alert, ToggleGroup, Sheet, Separator.
- `threejs-*` (cloudai-x/threejs-skills), `gsap-scrolltrigger`, `lightweight-3d-effects`, `modern-web-design`, `scroll-reveal-libraries` (freshtechbro/claudedesignskills).
- **Astryx** (Meta, `@astryxdesign/cli`) — тональные палитры из цветов SuluSystems (`app/src/theme/astryx/`) и токены движения (длительности, `--ease-standard`). Официального Astryx MCP нет, поэтому использован официальный CLI.
- **shadcn MCP** — подключён в `.mcp.json` корня репозитория (`npx shadcn@latest mcp`), активируется в новой сессии.
