# Урок 1. Отмечаем приход пациента

| Сцена | Реплика | На экране |
|---|---|---|
| Титул | Научимся отмечать в расписании, что пациент пришёл на приём. | титульная карточка, цели урока |
| Находим визит | Откройте «Расписание»: все визиты дня разложены по специалистам. | подсветка доски расписания |
| | Найдите нужный визит — например, Айгерим Нурланову в двадцать тридцать. | подсветка карточки «Айгерим Нурланова» |
| Отмечаем приход | Нажмите на карточку — откроется меню действий. | курсор кликает по карточке, появляется меню |
| | Выберите «Пришёл». | клик по «Пришёл» |
| | Портал подтвердит: клиент прибыл. | подсветка уведомления |
| | А счётчик «Пришли» сразу обновится. | подсветка счётчика «6 из 6» |
| Итоги | Итак, теперь вы умеете: находить визит в расписании и отмечать приход пациента. | пункты итогов |
| | Дальше — быстрая запись нового визита. | |
