**01 — Отмечаем приход пациента.** Цель: администратор находит визит в расписании и отмечает,
что пациент пришёл. Шаги: открыть «Расписание» → найти карточку визита → нажать на неё →
«Пришёл» → проверить уведомление «клиент прибыл» и счётчик «Пришли». Нужно знать: вход в портал
с правом на расписание. Данные в кадре: день клиники «Sulu Aesthetic», три специалиста, восемь визитов.

Тестовый урок для проверки скилла `/teach`: короткий, без сцены с кодом.
Запуск: Vite (`npx vite`, переменные в `.env.local`), вход и API подменены фикстурами по образцу
`tests/portal-smoke/canonical-routes.authenticated.spec.cjs`, расписание — в формате ответа
`GET /api/admin/schedule` из `useSchedule.js` и `ScheduleV2.page.test.jsx`.
